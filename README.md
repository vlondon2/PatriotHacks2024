# Byte-Sized Terms

## Introduction
Ever felt overwhelmed by the fine print of Terms & Conditions? **Byte-Sized Terms** is a Chrome extension designed to simplify legal jargon into bite-sized summaries, ensuring you fully understand what you’re signing up for. This extension automatically detects when you're on a T&C page and uses the OpenAI API to summarize key points into categories: **Good**, **Bad**, and **Neutral**.

## Features
- **Automatic Detection:** Instantly recognizes when you're on a Terms & Conditions page.
- **AI-Powered Summarization:** Utilizes the OpenAI API to extract and summarize important information from the text.
- **User-Friendly Interface:** Displays summarized content in a clear and concise popup, making it accessible for everyone.
- **Award-Winning Project:** Proudly secured **2nd place** in our hackathon track!

## Technologies Used
- **React:** For building the user interface.
- **Django:** As the backend framework.
- **Chrome Extensions:** For seamless integration with the browser.
- **Python:** For server-side processing.
- **OpenAI API:** To generate summaries of legal text.
